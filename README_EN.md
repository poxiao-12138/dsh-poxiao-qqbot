# Poxiao QQ Character Assistant

![Poxiao QQ Character Assistant settings](./assets/docs/poxiao-qq-settings.png)

`dsh-poxiao-qqbot` connects a QQ bot to DeepSeek Harness (DSH) and supports character settings, BreezeBlue TTS, Obsidian memory, and an optional game world.

See the [Chinese README](./README.md) for features and attribution.
