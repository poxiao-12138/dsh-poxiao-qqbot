# 踩坑清单 → 默认值 → 怎么改

每个默认值都来自实际踩坑；不是不能改，是改成别的之前先看一眼为什么。

| 坑 | 默认做法 | 配置项 | 关掉会怎样 |
|---|---|---|---|
| Breeze 不带终止标点会吃掉最后一个字 | 自动补「。」；已有标点或 `[...]` 结尾时不补 | `voice.autoPunctuation` | 可能吞字 |
| 音频结尾截断感 / 太硬 | 最后 30ms 淡出 + 尾部静音 1000ms | `voice.fadeMs` / `voice.padMs` | 结尾发闷或突兀 |
| 平台对格式挑剔 | 默认 wav；wav 发送失败自动再试 mp3 | `voice.outputFormat` | 只发 wav，失败就回落文字 |
| 16000Hz 单声道听感更稳 | 合成后统一重采样到 16k、混单声道 | `voice.sampleRate` / `voice.channels` | 音质变量更多 |
| `[[情绪:…]]` 被直接念出来 | 自动抽出当表演指令并从正文删除 | `voice.emotionMarkers` | 标记会被念出来 |
| 台词太书面、听感平 | 润色默认**关闭**（避免额外模型调用） | `voice.polish` + `voice.polishPrompt` | — |
| 语音又发文字刷屏 | 私聊默认只发语音，群聊默认文字 | `voice.mode` / `voice.groupVoice` | 改成 both 会语音+文字 |
| 想让她自己决定这条要不要语音 | 可选 `mode: auto`：回复里写 `[[语音]]` / `[[文字]]`，没写则走 `autoDefault` | `voice.mode` / `voice.autoDefault` | 改成 auto 后默认不再强制语音 |
| 长文本/链接不适合念 | 超过 `maxChars` 或含链接/代码 → 回落文字 | `voice.maxChars` / `voice.fallbackText` | 关掉则长内容不发 |
| 流式和语音抢发送 | 语音模式自动关流式 | （自动，无开关） | — |
| 合成失败整条没反应 | 默认重试 2 次，失败回落文字 | `voice.retries` / `voice.fallbackText` | — |
| 情绪强弱不好调 | 无情绪 2.6 / 有情绪 3.5 | `voice.guidanceScale` / `voice.guidanceScaleEmotion` | 太平或太用力 |
| Breeze 凭证重复填 | 复用 qq-voice-polish 的 `QQ_VOICE_POLISH_BREEZE` | `voice.apiKey` / `voice.voiceId` 可覆盖 | — |
| 机器人默认能执行本地命令/读文件 | 默认 `qqbot-safe` preset：无 shell/文件/编排工具，只留聊天/记忆/世界/搜索 | `im-qqbot.preset` | 换成 standard 才有完整本地能力 |
